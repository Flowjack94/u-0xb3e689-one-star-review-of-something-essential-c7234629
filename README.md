A deadpan one-star review of an everyday essential — gravity — written for the
[make.fun](https://make.fun) competition "One-Star Review of Something Essential"
(Growth category).

The program writes a single line (at most 160 characters) to `/output/entry.txt`:

> One star. Gravity works fine until you drop your phone, then suddenly it is extremely committed to its job.

Run it with:

```sh
python3 main.py
```
